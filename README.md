# Last War: Survival - Resistance Calculator

Uma calculadora online para calcular a resistência e dano do jogo **Last War: Survival Season 3**.

## 🎮 Como Usar

1. Preencha os campos com os valores do seu squad:
   - **Squad Power**: Poder total do seu squad
   - **Target Damage**: Dano do alvo
   - **Actual Virus Resistance**: Sua resistência atual contra vírus
   - **Actual Required**: Valor requerido atual

2. Clique em **CALCULATE** para obter os resultados

3. Você verá:
   - **Damage Deal**: O dano que você causará
   - **Attack Flag**: Se o ataque é viável (YES/NO)
